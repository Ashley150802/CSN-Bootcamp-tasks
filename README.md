# AWS Bootcamp Tasks Repository

This repository contains all my weekly task submissions and progress reports from the **AWS Cloud Bootcamp**. Each file documents the activities, screenshots, and deliverables for a specific week, showcasing my hands-on learning experience with various AWS services.

---

 Repository Structure

All weekly reports are organized inside the `/CSN` folder:

Week  File  Description 

| Week 1–2 : Introduction to AWS, account setup, IAM users, billing alerts, and understanding the AWS Management Console. 

| Week 3 : Explored EC2 instances, SSH key pairs, and basic Linux commands on AWS. 

| Week 4 : Configured S3 buckets, object storage, permissions, and versioning. 

| Week 5 : Deployed a static website using S3 and configured public access policies. 

| Week 6 : Set up AWS CloudFront for content distribution and caching optimization. 

| Week 7 : Worked with RDS to launch and connect to a MySQL database instance. 

| Week 8 : Implemented AWS VPC concepts including subnets, route tables, and security groups. 

| Week 9 : Used CloudWatch for monitoring and setting alarms for EC2 metrics. 

| Week 10 : Completed final project combining EC2, S3, and RDS with IAM roles and automation scripting.
